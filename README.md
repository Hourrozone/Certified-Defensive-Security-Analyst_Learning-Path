# 🛡️ SOC Analyst Learning Path — HTB Academy Notes

## 📖 About This Repository

Welcome to this repository! This project documents my learning journey through the **SOC Analyst path from Hack The Box (HTB) Academy**, covering all **15 modules**.

The purpose of this repository is to provide a free, structured collection of study notes for anyone interested in learning about Security Operations Center (SOC) operations, defensive security, threat detection, incident investigation, and digital forensics.

Whether you are an aspiring SOC Analyst, a cybersecurity student, or someone looking to strengthen your blue team knowledge, these notes are intended to help you understand the concepts and techniques commonly used in real-world security operations.

## 🎯 Learning Objectives

Throughout these 15 modules, you will explore several important areas of defensive security, including:

- **SOC Fundamentals:** Understanding SOC operations, analyst responsibilities, and security monitoring concepts.
- **Log Analysis and SIEM:** Working with security logs, investigating events, and understanding how SIEM platforms support threat detection.
- **Threat Detection:** Learning how to recognize suspicious activities, attack patterns, and indicators of compromise (IOCs).
- **Detection Engineering:** Understanding YARA and Sigma rules and how they can be used to identify malicious files and suspicious events.
- **Windows Security Monitoring:** Learning to identify common Active Directory attacks and suspicious Windows activities.
- **Network Security Monitoring:** Understanding network traffic analysis, packet inspection, and common network-based attacks.
- **Malware Analysis:** Exploring malware analysis concepts and techniques, including JavaScript deobfuscation.
- **Digital Forensics:** Exploring memory forensics, disk forensics, evidence acquisition, and forensic investigation techniques.
- **Incident Response and Reporting:** Understanding the incident reporting process, evidence documentation, and effective security communications.

## ⚠️ Important Limitations

**This repository is completely free to access, but it has some limitations.**

The documentation primarily focuses on explaining concepts, techniques, commands, and demonstrations from the learning material.

It is important to understand what this repository does and does not provide:

| Included | Not Included |
|---|---|
| Learning notes and explanations | Downloadable learning resources |
| Technical demonstrations | Guided practical exercises |
| Command examples and references | Dedicated practical lab environments |
| Detection concepts and techniques | Hands-on lab walkthroughs |
| Attack detection explanations | Additional tools or preconfigured environments |
| Investigation methodologies | Real-world datasets for independent practice |

In other words, this repository is designed to help you **understand the theory and follow the demonstrations**, rather than provide a complete hands-on training environment.

You may need to obtain your own tools, datasets, virtual machines, and lab environments if you want to practice the techniques independently.

1. Start with the first module and follow the documentation in sequence.
